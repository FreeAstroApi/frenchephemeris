# FrenchEphemeris — architecture and decisions

Goal: replace Swiss Ephemeris in FreeAstroAPI with an independently implemented,
faster, thread-safe engine whose numbers come from JPL, and whose astrology
semantics (houses, ayanamsas, flags, nodes, Lilith) match the Swiss behaviour
that the API exposes today.

## Sources of truth

| Concern | Authority |
|---|---|
| Planet/Moon/Sun states | JPL DE441 (years ≈ 0–1550) + DE442 (1550–2650), re-encoded into FEPK (docs/FORMAT.md) |
| Minor bodies (Chiron, Pholus, Ceres, Pallas, Juno, Vesta, Eris, Eros) | JPL sb441-n16 (DE441 perturbers) and JPL Horizons small-body SPKs, re-fitted into `fepk-minor-v2.bin` (docs/MINOR_BODIES_REPORT.md) |
| Further numbered asteroids (~300 bundled, any other on demand) | JPL Horizons small-body SPKs re-fitted into `fepk-asteroids-v1.bin` / `ast_<n>.bin` by `frenchephemeris.asteroids` (docs/ASTEROIDS_REPORT.md) |
| Time scales, precession, nutation, sidereal time | IAU 2006/2000 resolutions, validated against ERFA (pyerfa) |
| Delta T | versioned model (see `time::DELTA_T_MODEL`) |
| Astrology conventions | published definitions, calibrated black-box against the licensed `pyswisseph==2.10.3.2` oracle (public API only — never Swiss source) |

When JPL and Swiss disagree physically, JPL wins and the difference is reported.
When they disagree on a *definition* (ayanamsa zero point, house edge rule),
Swiss behaviour is the compatibility target.

## Layout

```
crates/fe-core     Rust kernel (no global state, Send + Sync everywhere)
  math.rs          Vec3/Mat3, angles (shared)
  pack.rs          FEPK reader, Chebyshev evaluation
  time.rs          calendars, Delta T, TT/TDB
  frames.rs        precession, nutation, obliquity, GMST/GAST
  ephem.rs         light time, deflection, aberration, frames, topocentric
  houses.rs        house systems P K O R C T E W + house position
  houses/          the other Swiss systems (A V D N B X F M H U Y L Q S I i G J), speeds,
                   Gauquelin sectors, house names
  ayanamsa.rs      sidereal modes 0–46 (44 implemented), user mode, SIDBIT options
  points.rs        mean/true node, mean/true Lilith
  context.rs       immutable CalcContext + body ids + batch API
  eclipses.rs      solar/lunar eclipses: Besselian elements, Danjon shadow, local circumstances, saros
  occultations.rs  lunar occultations of planets and stars (eclipse geometry, other target)
  lunar_local.rs   lunar eclipses visible from a place (lun_eclipse_when_loc)
  extras.rs        ECL_NUT, calc_pctr, helio_cross, mooncross_node, sidtime0, UTC via the engine
  utc.rs           UTC with IERS leap seconds, time zones, date checks
  util.rs          split_deg, centisecond helpers, normalisation, body/ayanamsa names
crates/fe-py       PyO3 bindings -> python package `frenchephemeris`
tools/             offline pack builders (Python; SPK types 2/21, HTTP ranges; fit_minor.py)
harness/           differential tests vs JPL direct, Swiss oracle, Horizons
bench/             speed benchmarks vs pyswisseph
data/              (gitignored) source kernels and built packs
```

## Conventions

- Radians internally; degrees at `houses`, `ayanamsa`, `points` and the adapter edge.
- Time arguments are JD with scale suffix: `jd_ut`, `jd_tt`, `jd_tdb`.
- Matrices are row-major and rotate vectors (`v_new = M · v`), SOFA rotation conventions.
- Positions km, velocities km/day internally.
- Test fixtures generated by Python scripts live in `crates/fe-core/tests/fixtures/<area>/`
  together with the script that produced them (`gen_*.py`), so they are reproducible.
- Fixtures (and reports) containing Swiss Ephemeris oracle outputs are **not** in the public
  tree: they live in the private corpus `$FE_ORACLE_DIR` (default `private/oracle/`,
  gitignored) under the same relative paths; generators write there directly. Tests that
  need them call `require_oracle!` (`crates/fe-core/tests/common/mod.rs`) and are skipped
  when the corpus is absent. `tools/privatize_oracle_fixtures.py` (re)applies the split
  and `--check` verifies the public tree.
- One private layout, `private/` (gitignored): `private/oracle/<repo path>` for oracle
  fixtures and reports (mirrors the tree; `FE_ORACLE_DIR`), and named datasets that a
  deployment may load, currently `private/stars/` (star-name compatibility table,
  `FRENCHEPHEMERIS_STAR_COMPAT`).

## Python environment

`.venv` (Python 3.12) has numpy, jplephem, pyerfa, pyswisseph 2.10.3.2, maturin, pytest.
Swiss oracle ephemeris files: the Swiss Ephemeris data directory (`SE_EPHE_PATH`) (read-only; oracle only,
never shipped or used to build data).
