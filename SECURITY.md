# Security policy

FrenchEphemeris is published by Gabriel Naulleau EI, trading as FreeAstroAPI (the
"maintainer"). This page explains how to report a vulnerability and what to expect.

## Reporting a vulnerability

Please **do not** open a public issue for a suspected vulnerability.

- Email **contact@freeastroapi.com** with the subject line `SECURITY: FrenchEphemeris`.
- If the repository has GitHub private vulnerability reporting enabled, you may use
  *Security → Report a vulnerability* instead.
- Include: affected version or commit, a description, steps or a proof of concept to
  reproduce, the impact you observed, and whether the issue is already public.

## What happens next

| Step | Target |
|---|---|
| Acknowledgement of your report | within 3 business days |
| Initial assessment (valid / not valid, severity) | within 10 business days |
| Fix or mitigation for confirmed issues | as soon as practicable, prioritised by severity |
| Public advisory and credit (if you wish) | when a fix is available, or by agreement |

We follow coordinated disclosure: please give us a reasonable time to fix the issue before
publishing details. We will keep you informed of progress.

Where the law requires it — in particular the notification of actively exploited
vulnerabilities and severe incidents under the EU Cyber Resilience Act (Regulation (EU)
2024/2847) — the maintainer notifies the competent authorities within the legal deadlines.

## Supported versions and support period

Security fixes are released in the latest version of FrenchEphemeris, which every user can
install free of charge: under the AGPL-3.0, and under the commercial licence, which covers
all updates (see COMMERCIAL-LICENSE.md). The support period for security updates is at
least five years from the release of each version; users of an older version receive them
by upgrading to the latest version. There is no separate support or service-level
commitment.

## Scope

In scope: the Rust core (`crates/fe-core`), the Python bindings (`crates/fe-py`,
`python/frenchephemeris`), the pack file reader, and the tools shipped in this
repository. Examples of relevant issues: memory-safety or panic conditions triggered by a
crafted pack file or crafted inputs, path handling in pack/cache loading, unsafe network
handling in the optional asteroid downloader.

Out of scope: the accuracy of astronomical or astrological results (please open a normal
issue), third-party services such as JPL Horizons, and deployments operated by others.

## Software bill of materials

Each release includes a software bill of materials (SPDX format) generated by
`tools/gen_sbom.py`, listing the Rust and Python components and their licences.
